# Architecture Decision Records

ADRs capture decisions with long-term cost or cross-module impact.

## Format

Each ADR contains status, context, decision, consequences, rejected alternatives, and reconsideration triggers. Accepted ADRs are immutable except status/links; a changed decision receives a new ADR that supersedes the old one.
